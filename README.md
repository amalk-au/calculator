# JavaScript Calculator

A simple web-based calculator built using HTML, CSS and JavaScript. Supports basic arithmetic operations through a clean, responsive interface.

**Live Demo:** [https://amalk.au/calculator/](https://amalk.au/calculator/)

## Features

- Basic arithmetic operations (addition, subtraction, multiplication and division).

- Chain calculations.

- Clear input using the AC button.

- Display supports up to 10 digits.

- Handles division by zero.

- Responsive and user-friendly interface.

## Tech Stack

- HTML5

- CSS3

- JavaScript

- GitHub Pages (hosting)

## Getting Started

### Installation

1.  Clone the repository:

    ```
    git clone https://github.com/amalk-au/calculator.git
    ```

2.  Navigate to the project directory:

    ```
    cd calculator
    ```

3.  Open `index.html` in your browser.

No additional dependencies or installation steps are required.

## Usage

1.  Click the number buttons to enter a number.

2.  Select an arithmetic operator (`+`, `-`, `*`, `/`).

3.  Enter the second number.

4.  Press `=` to display the result.

5.  Press `AC` to clear the calculator and start again.
